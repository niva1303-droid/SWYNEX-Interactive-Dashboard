# 🏋️‍♂️ Interactive Gym Membership Dashboard

## 📌 Project Overview
Created an interactive Power BI dashboard using the Gym Membership Dataset to analyze member demographics, membership distribution, gym attendance, workout duration, and additional service usage.

## 🧰 Tools Used
- Power BI
- DAX
- Data Visualization

## 📊💹 Dashboard Features
- **KPI Cards:** Total Members, Average Age, Average Weekly Visits, Average Gym Time, Premium Membership %, and Personal Training %.
- **Membership Analysis:** Standard vs. Premium membership distribution.
- **Age Group Analysis:** Member distribution across age groups.
- **Attendance Analysis:** Average weekly visits by membership type.
- **Workout Duration:** Average gym time by membership type.
- **Service Usage:** Personal training, group lessons, and sauna participation.
- **Interactive Filters:** Membership Type, Age Group, Gender, and Personal Training.

## 🔖 Key Insights
- Standard and Premium memberships are almost equally distributed.
- Members aged 26–45 account for 53.8% of the dataset.
- Both membership types have similar average weekly visits and gym duration.
- Personal training has a participation rate of 51.8%.
- Age shows virtually no linear relationship with gym duration.

## Objective
To present key findings through an interactive dashboard that supports clear exploration of gym membership patterns and service usage.
